## What you get

- **Edge-first.** Runs on Cloudflare Workers, Bun and Node.js.
- **Fully typed.** Built on `discord-api-types`.
- **Handler-based.** Commands, components, modals and webhooks each get their own handler.
- **Secure by default.** Every request's signature is verified for you.
- **Familiar builders.** discord.js builders are re-exported for embeds, buttons and modals.
- **Autocomplete built in.** A helper for slash command autocomplete.
