## Variable Types

Fields that are optional and can be `undefined` are suffixed with `?`. Field values that can be `null` are prefixed with a `?`.

### Example

| Field Name                | Type    |
| ------------------------- | ------- |
| optionalField?            | string  |
| nullableField             | ?string |
| nullableAndOptionalField? | ?string |
